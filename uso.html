Introduccion

Para operar nuestro proyecto, se puede utilizar una aplicación móvil o, alternativamente, controlar el sistema mediante el código Arduino a través de una computadora. La aplicación ha sido diseñada con una interfaz sencilla, permitiendo al usuario controlar el invernadero de manera intuitiva mediante la activación de botones.

Conexion del dispositivo

El Arduino se conecta con el dispositivo móvil a través de la aplicación, la cual dispone de una función de conexión vía Bluetooth. Esta comunicación permite manipular y controlar los diferentes componentes del sistema de forma remota y eficiente.

Botones

Los botones de la aplicación presentan un diseño sencillo e intuitivo, lo que facilita su comprensión y uso. Las funciones asociadas a cada botón son básicas, permitiendo al usuario controlar el sistema de manera directa y eficiente.

Uso

El uso de la aplicación para el control del invernadero es sumamente sencillo, ya que no requiere conocimientos técnicos avanzados para su manejo. Basta con presionar los botones correspondientes para disfrutar de un control directo y eficiente del invernadero desde la comodidad de un dispositivo móvil.
